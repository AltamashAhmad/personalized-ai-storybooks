## 🛠️ Tech Stack & Production Triad

* **Frontend & SSR:** Next.js 14 (App Router, TypeScript, Tailwind CSS, Framer Motion)
* **Interactive 3D Reader:** StPageFlip (`page-flip`) / Canvas / CSS3D
* **Primary Story Engine:** Claude Sonnet 5 (`claude-sonnet-5`) — $0.036 USD per book
* **Fallback Story Engine:** GPT-5.6 Sol (`gpt-5.6-sol`) — $0.073 USD per book
* **Utility & Moderation Engine:** Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`) — $0.0016 USD per book
* **Illustration Engine:** Flux.1 Schnell / Dev via fal.ai — $0.36 USD for 12 spreads
* **Payments & MoR:** LemonSqueezy (One-tap Apple Pay, global tax handling, zero UAE trade license required)
* **PDF Compilation:** Puppeteer / Chromium 300 DPI CMYK PDF 1.4
